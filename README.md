# LinkedIn Bot

Este es un bot automatizado para enviar solicitudes de conexión en LinkedIn utilizando Selenium.

## 🚀 Características
- Inicia sesión en LinkedIn de forma automática.
- Acepta cookies si es necesario.
- Navega hasta la sección de solicitudes de conexión.
- Envía solicitudes de conexión a los perfiles listados.

## 🔧 Instalación
### 1️⃣ Clonar el repositorio
```sh
git clone https://github.com/TU_USUARIO/bot-linkedin.git
cd bot-linkedin
```

### 2️⃣ Instalar dependencias
Asegúrate de tener **Python 3.x** y ejecuta:
```sh
pip install selenium
```

### 3️⃣ Configurar WebDriver
Debes descargar y configurar el **WebDriver** correspondiente a tu navegador (por ejemplo, [Geckodriver](https://github.com/mozilla/geckodriver) para Firefox).

## 🚀 Uso
Ejecuta el script con:
```sh
python linkding_bot.py
```

⚠️ **IMPORTANTE**: Asegúrate de completar tus credenciales en el código antes de ejecutarlo.
